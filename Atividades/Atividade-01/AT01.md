# 🎲 Criando o Primeiro Banco de Dados

Vamos criar um Banco de Dados com as **10 cidades mais populosas do mundo**.

## 📊 Estrutura da Tabela

```mermaid
erDiagram
    MaioresCidades {
        int ID PK "Gerado Automaticamente"
        varchar NOME "Armazena o Nome da Cidade"
        varchar PAIS "Armazena o Nome do País onde a Cidade se Localiza"
        int POPULACAO "Armazena a Quantidade de Habitantes"
    }
```

## 📋 Criando a Tabela

Depois, com nossa Database já conectada ao **PostgreSQL Explorer**, vamos criar um novo arquivo de query para a database e criar a nossa tabela com o seguinte código:

```postgresql
CREATE TABLE MaioresCidades(
    id INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    pais VARCHAR(100) NOT NULL,
    populacao INT NOT NULL DEFAULT 0
);
```

## 🌎 Adicionando as Cidades

Antes, pesquisamos quais são as **10 cidades mais populosas do mundo** e organizamos os dados.

Usamos a [Wikipédia](https://pt.wikipedia.org/wiki/Lista_das_cidades_mais_populosas_do_mundo) como fonte.

Ficamos com o seguinte resultado:

| Nome | País | População |
| --- | --- | ---: |
| Tóquio | Japão | 37.468.000 |
| Déli | Índia | 28.514.000 |
| Xangai | China | 25.582.000 |
| São Paulo | Brasil | 21.650.000 |
| Cidade do México | México | 21.581.000 |
| Cairo | Egito | 20.076.000 |
| Mumbai | Índia | 19.980.000 |
| Pequim | China | 19.618.000 |
| Daca | Bangladesh | 19.578.000 |

> **⚠️ Observação:** Os dados foram retirados de uma estimativa da ONU de 2018 e estão desatualizados. O uso desses dados aqui é apenas "estético".

Agora vamos inserir as cidades na tabela com o seguinte código:

```postgresql
INSERT INTO MaioresCidades(nome, pais, populacao)
VALUES
('Tóquio', 'Japão', 37468000),
('Déli', 'Índia', 28514000),
('Xangai', 'China', 25582000),
('São Paulo', 'Brasil', 21650000),
('Cidade do México', 'México', 21581000),
('Cairo', 'Egito', 20076000),
('Mumbai', 'Índia', 19980000),
('Pequim', 'China', 19618000),
('Daca', 'Bangladesh', 19578000);
```
